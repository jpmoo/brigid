# Brigid

A self-hosted novel writing application, named after the Celtic goddess of poetry.

Single-user by design: authentication is tailored to one owner, not multi-tenancy.

## Status

Pre-spec. Nothing implemented yet.

## Intended environment

- **Runtime target:** headless Ubuntu server
- **Database:** PostgreSQL
- **Deployment:** self-hosted, single user

## Repository

Private. Development happens on macOS; the app runs on a separate Ubuntu host.
